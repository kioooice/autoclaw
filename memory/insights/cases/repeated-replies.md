# Case: 重复回复问题

## 问题
Agent 对同一个问题重复回复十几遍。

## 现象
- 2026-03-20 用户反馈：一个问题重复回复十几遍
- 发生在 webchat channel
- 重置配置后出现

## 根因
AutoClaw 应用启动时刷新 `zai` provider 的 JWT token（24h 过期），写入 openclaw.json，但 Gateway 没有正确处理配置变化，导致状态异常。

## 解决方案
在 OpenClaw 应用界面点击 **重置连接**。

**修复选项对比**：
| 选项 | 效果 |
|------|------|
| 重新连接 | ❌ 无效 |
| 重置连接 | ✅ 可修复 |

## 状态
**已解决** (2026-03-20)

## 长期建议
这是 OpenClaw 的 bug，建议反馈给开发团队：
1. Gateway 应该能正确热重载配置变化
2. 或者应用刷新 token 后自动触发 Gateway 重启
