# Case: 重复回复问题

## 问题
Agent 对同一个问题重复回复十几遍。

## 现象
- 2026-03-20 用户反馈：一个问题重复回复十几遍
- 发生在 webchat channel

## 可能原因
1. 消息队列积压
2. 心跳机制重复触发
3. Gateway 连接问题导致重试
4. 模型输出问题

## 待排查
- [ ] 检查 Gateway 日志
- [ ] 检查是否有重复消息入队
- [ ] 检查心跳配置

## 解决方案
在 OpenClaw 应用界面重启 Gateway。

## 根因
重置配置后 Gateway 状态异常，导致消息重复输出。

**已解决** (2026-03-20)
