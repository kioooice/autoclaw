# Horizon News Agency

🚀 **AI 科技新闻策展人** - 自动生成双语科技新闻简报

## 快速开始

在这个对话中，只需输入：

```
1
```

即可触发 Horizon News 生成今日科技新闻简报。

## 功能特性

- 📡 **多源聚合**: Hacker News, RSS, Reddit, GitHub
- 🤖 **AI 智能评分**: 0-10 分自动筛选高质量新闻
- 🌐 **双语输出**: 中英文对照，便于阅读
- 💬 **社区讨论**: 汇总 HackerNews、Reddit 等评论精华
- 🔍 **背景知识**: 自动搜索补充技术背景
- 🔗 **智能去重**: 合并不同平台的重复内容

## 工作流程

```
输入 "1" → 触发 Agency → 收集新闻 → AI 评分 → 生成简报 → 输出结果
```

## 输出示例

生成的简报包含：
- 📰 新闻标题和 AI 评分
- 📝 内容摘要（中英文）
- 💭 社区讨论精选
- 📚 相关背景知识
- 🔗 原文链接

## 配置说明

如需自定义配置，可编辑以下文件：
- `agency.yaml` - Agency 主配置
- `launcher.json` - 触发器和执行配置

1. 输入 `1` 触发今日简报生成
2. 生成过程通常需要 2-5 分钟
3. 可随时重新输入 `1` 获取最新内容
4. 简报会自动保存为 Markdown 格式
