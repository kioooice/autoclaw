## 优惠开通方案

### 方案 1：学生/教师免费

**适用人群：** 在校学生、教师

**步骤：**
1. 访问 https://education.github.com
2. 用学校邮箱认证身份
3. 获得 GitHub Student Developer Pack
4. 包含 Copilot Pro 免费使用权

**福利：**
- Copilot Pro 免费
- GitHub Pro 免费
- 多个开发者工具免费/折扣

---

### 方案 2：开源维护者免费

**适用人群：** 热门开源项目维护者

**步骤：**
1. 确保你的 GitHub 项目有一定 star 数
2. 在 GitHub Education 页面申请
3. 通过后获得免费 Copilot Pro

---

### 方案 3：年付优惠

**适用人群：** 决定长期使用的用户

| 方案 | 月付 | 年付 | 节省 |
|------|------|------|------|
| Pro | $10/月 | $100/年 | $20 (17%) |
| Pro+ | $39/月 | $390/年 | $78 (17%) |

---

### 方案 4：新用户试用

**适用人群：** 新用户

- **Pro 版**：30 天免费试用
- 无需信用卡即可开始

---

### 方案 5：免费版 + 手动补充

**策略：** 先用免费版，不够时升级

**计算：**
- Free 版每月 50 次 Agent 请求 + 2,000 次补全
- 如果轻度使用可能够用
- 不够时再升级 Pro

## 省钱技巧

### 1. 年付代替月付
- 省 17%（相当于两个月免费）

### 2. 学生身份认证
- 完全免费获得 Pro

### 3. 开源贡献者申请
- 热门项目维护者免费

### 4. 合理使用免费额度
- Free 版的 50 次请求 + 2,000 补全可能够轻度使用
- 可以先用免费版评估是否需要升级

### 5. 团队共享（企业版）
- Business 版有团队协作功能
- 多人共用可能更划算
