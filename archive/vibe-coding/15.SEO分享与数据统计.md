# 第十五章：SEO、分享与数据统计

## 一句话总结
做好了网站没人来？让搜索引擎找到你、社交平台展示你、统计工具告诉你谁来了。

---

## 1. SEO（搜索引擎优化）

**问题：** 百度谷歌翻十页找不到你的网站

**原因：** 搜索引擎的爬虫是"瞎子"，你需要给它指路。

### 三个基础配置

| 配置 | 作用 | 怎么做 |
|------|------|--------|
| **Metadata** | 告诉爬虫你是谁 | Next.js 的 `layout.tsx` 里配置 title + description |
| **Sitemap** | 网站的地图 | 告诉爬虫有哪些页面 |
| **Robots.txt** | 爬虫的规则 | 哪些能爬、哪些不能 |

### 进阶 SEO
- 结构化数据 → 让搜索引擎更好理解内容
- Core Web Vitals → Google 的页面体验指标
- 移动端友好 → 重要排名因素

**SEO 是长期活，不会一夜排第一，但坚持会逐渐上升。**

---

## 2. Open Graph（社交分享）

**问题：** 发链接到群里只显示蓝色链接 → 没人想点

**解决：** 配置 OG 协议 → 显示精美大图 + 引人入胜的标题

### Next.js 做法
放一张图片 `opengraph-image.png` → 自动生成 OG 标签 → 社交平台抓取显示大图

**效果对比：**
- 没配 OG → 蓝色链接，点击率低
- 配了 OG → 大图 + 标题，点击率暴涨

**OG 优化不是可选项，是营销基础设施。**

---

## 3. 数据统计（Umami）

**问题：** 不知道每天多少人访问、从哪来、用什么设备

### 为什么用 Umami？
- 自部署（用 1Panel 一键装）
- 隐私友好（不追踪个人信息）
- 轻量（一小段 JS 代码）
- 免费

### 关注什么指标？
| 指标 | 说明 |
|------|------|
| PV（页面浏览量） | 总共看了多少页 |
| UV（独立访客） | 多少不同的人来看 |
| 跳出率 | 看了一页就走的比例 |
| 来源 | 从哪里来的（搜索/社交/直接） |
| 设备 | 手机还是电脑 |

**数据驱动决策：** 统计数据 + 用户反馈 = 知道该做什么

---

## 4. 法律合规

**不是可选项，是必修课。**

| 合规项 | 说明 |
|--------|------|
| 隐私政策 | 收集用户数据必须告知用途、存储方式、用户权利 |
| 用户协议 | 服务条款、免责声明 |
| ICP 备案 | 服务器在中国大陆必须备案 |
| GDPR | 面向欧盟用户时需遵守（违规巨额罚款） |
