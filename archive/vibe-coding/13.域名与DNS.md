# 第十三章：域名、DNS 与网络接入

## 一句话总结
平台给的默认链接有限制。买个自己的域名，绑上去，别人才能稳定访问。

---

## 为什么需要域名？

平台默认链接 → 可能有访问限制、不好记、不专业
自己的域名 → `myapp.com` → 好记、专业、没限制

**比喻：** 域名是互联网的通讯录。你搜"妈妈"，手机帮你拨号。浏览器搜 `myapp.com`，DNS 帮你找到服务器。

---

## DNS 是什么？

**Domain Name System（域名系统）**

把人类能读的域名翻译成服务器的 IP 地址：
```
myapp.com → DNS 查询 → 1.2.3.4（服务器 IP）
```

---

## 买域名

| 注册商 | 说明 |
|--------|------|
| Cloudflare | 价格最透明，按成本价卖 |
| Namecheap | 老牌，经常有优惠 |
| 阿里云/腾讯云 | 国内方便，但需要备案 |

**建议：** 花几十块买个正经的 `.com`，别用免费二级域名（房东随时能踢你走）

---

## DNS 配置

买完域名后，设置 DNS 记录指向你的服务器：

| 记录类型 | 用途 | 例子 |
|---------|------|------|
| A 记录 | 域名 → IP 地址 | `myapp.com → 1.2.3.4` |
| CNAME 记录 | 域名 → 另一个域名 | `www.myapp.com → myapp.com` |
| TXT 记录 | 验证域名所有权 | 部署平台要求的验证 |

---

## HTTPS（绿锁）

现代网站必须 HTTPS，浏览器会给 HTTP 网站标"不安全"。

**部署平台通常自动申请 SSL 证书**，不需要手动操作。

---

## 备案

**国内服务器必须 ICP 备案**，否则网站会被封。

**免备案方案：**
- 用香港/海外服务器
- 用 Vercel/Cloudflare 等海外平台
- 用 EdgeOne/ESA 的海外节点

---

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 域名解析不生效 | DNS 缓存还没刷新 | 等几分钟，或 `ipconfig /flushdns` |
| 403 Forbidden | 平台限制默认链接 | 绑定自定义域名 |
| 证书报错 | HTTPS 没配好 | 检查 SSL 证书是否生效 |
