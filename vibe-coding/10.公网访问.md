# 第十章：Localhost 与公网访问

## 一句话总结
localhost 只有你自己能访问。想让别人看到，需要内网穿透或部署到公网。

---

## 小明的尴尬

把 `http://localhost:3000` 发到微信 → 朋友打不开
**原因：** localhost = "我自己的电脑"，别人访问的是他自己的电脑

---

## 网络的三个层级

| 层级 | 是什么 | 谁能访问 |
|------|--------|---------|
| **localhost** | 你的电脑 | 只有你自己 |
| **局域网 (LAN)** | 同一个 WiFi 下的设备 | 同网络的人 |
| **互联网 (WAN)** | 全世界 | 所有人 |

---

## 从 localhost 到局域网

在局域网里让别人访问：
```bash
# 启动时绑定 0.0.0.0
pnpm dev --host 0.0.0.0
```
然后同 WiFi 的人用你的局域网 IP 访问：`http://192.168.x.x:3000`

**常见问题：防火墙挡了** → 需要放行端口

---

## 内网穿透：临时让朋友看看

把你的 localhost 暴露到公网，适合临时演示。

### Cloudflare Tunnel（推荐）
- 免费
- 不需要公网 IP
- 一条命令搞定

### 备选方案
- ngrok
- localtunnel
- Tailscale Funnel

**注意：**
- 关掉终端链接就失效了（临时方案）
- 不要在上面跑生产服务
- 注意别暴露敏感数据

---

## 为什么最终需要部署？

内网穿透是临时方案，关机就没了。想让链接一直能用，需要**部署到云平台**（第十二章）。

**流程：**
```
localhost → 内网穿透（临时演示）→ 部署到云平台（永久在线）
```
