# 6.0 领取你的数据库

## 一句话总结
注册一个免费的云端 PostgreSQL 数据库，拿到连接字符串，验证能连上就行。

---

## 为什么不用本地数据库？

| 方式 | 问题 |
|------|------|
| 本地安装 | 配置繁琐，容易踩坑 |
| 云端数据库 | 注册即用、自动备份、部署时不用迁移 |

**结论：** 新手直接用云端，免费套餐对个人项目绑绑有余。

---

## 方案一：Neon（推荐 ⭐）

专注 PostgreSQL，无服务器架构，免费额度大。

### 注册 3 步走

1. **注册** → neon.tech，用 GitHub 登录
2. **建项目** → 名字随便起，Region 选 Singapore（国内延迟最低）
3. **拿连接字符串** → 格式：postgresql://用户名:密码@ep-xxx.neon.tech/neondb?sslmode=require

### 免费额度
- 存储：512 MB
- 计算时长：100 小时/项目
- 项目数：100 个
- 分支：10 个

---

## 方案二：Supabase

PostgreSQL + 认证 + 存储 + 实时订阅，全家桶。

### 注册 3 步走
1. 注册 → supabase.com，用 GitHub 登录
2. 建项目 → 填组织名、项目名、设置密码，Region 选 Singapore
3. 拿连接字符串 → 点顶部 Connect，Method 选 Transaction pooler

### 免费额度
- 数据库存储：500 MB
- 文件存储：1 GB
- 带宽：5 GB/月
- 项目数：2 个

---

## Neon vs Supabase 怎么选？
- 只要数据库 → **Neon**（专注、轻量、额度大）
- 要全家桶 → **Supabase**
- 本教程推荐 → **Neon**（不被平台捆绑）

---

## 连接字符串怎么保管？

**⚠️ 这是数据库的钥匙，绝对不能提交到 GitHub 或发给别人！**

存到项目根目录的 .env 文件，确保 .gitignore 里有 .env。

---

## 验证连接（3 种方式）
1. 让 AI 验证："用我 .env 里的 DATABASE_URL 测试连接"
2. Drizzle Studio：pnpm drizzle-kit studio
3. 平台控制台：Neon/Supabase 后台直接看表数据

---

## 常见连接问题
- Invalid URL → 检查格式、空格、引号
- password authentication failed → 去平台重置密码
- connection refused → 加 ?sslmode=require
- too many connections → 用连接池地址

---

## 连接池是什么？
**一句话：** 预先建好一批连接，借出去用完还回来。
**比喻：** 共享单车。100 个人不需要 100 辆车。
**部署时必须用连接池地址！**
