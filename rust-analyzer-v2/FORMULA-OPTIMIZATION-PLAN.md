# 配方优化模型方案

## 项目背景

工件通过钝化和封闭处理后，需要查看防锈情况。希望通过机器学习实现：
1. **正向预测**：给定配方 → 预测防锈效果
2. **逆向优化**：目标效果 → 推荐最优配方

## 业务场景

```
配方参数 ──→ 封闭处理 ──→ 防锈检测 ──→ 结果评估
    │                                      │
    └──────── 能否建立关联/逆向预测？ ──────┘
```

## 数据需求

### 最小数据表结构

```csv
批次ID,成分A浓度,成分B浓度,pH值,封闭温度,封闭时间,钝化温度,钝化时间,工件材质,铁锈占比,盐雾等级,备注
001,25.0,8.5,5.5,55,12,35,5,碳钢,0.85,96h,正常
002,22.0,7.0,5.2,50,10,30,4,碳钢,1.20,72h,pH偏低
```

### 数据量与效果

| 数据量 | 可实现功能 | 准确率 |
|--------|------------|--------|
| 300+ | 正向预测 | 75-80% |
| 500+ | 正向预测 + 简单优化 | 80-85% |
| 1000+ | 双向预测 + 智能优化 | 85-92% |
| 2000+ | 高精度模型 + 异常诊断 | 90-95% |

## 技术方案

### 模型选择

| 任务 | 推荐模型 | 说明 |
|------|----------|------|
| 正向预测 | XGBoost / 随机森林 | 表格数据，效果好 |
| 逆向优化 | 贝叶斯优化 + 高斯过程 | 寻找最优解 |
| 综合方案 | 神经网络 (MLP) | 端到端学习 |

### 系统架构

```
数据收集层：配方参数 + 处理条件 + 检测结果
    ↓
模型层：正向预测模型 + 逆向优化模型
    ↓
应用层：效果预测、配方推荐、参数优化、异常预警
```

## 数据收集策略

1. **历史数据整理**：查找过去1-2年的生产记录，预计 300-500 条
2. **DOE实验设计**：正交实验/均匀设计，用少量实验获得最大信息量
3. **日常积累**：每批次记录配方和结果，配合图片检测系统
